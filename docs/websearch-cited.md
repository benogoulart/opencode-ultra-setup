# opencode-websearch-cited

> **Original project:** https://github.com/ghoulr/opencode-websearch-cited

Web search with **inline citation and source**. Configured as the **last plugin** in the list (it affects other plugins' auth) and using `google`/`openai` providers as fallback.

> ⚠️ The plugin must be **last** in the `plugin` list of `opencode.jsonc`.
